 The Complete Visual Data Journey Summary:


1. MongoDB Database: Holds a document like { _id: "65cdb...", title: "Buy Milk" }.

2. Backend API: Transmits this JSON data over the network via your /getUserNotes endpoint.

3. NoteState.jsx (getNotes): Fetches the JSON, reads the array, and stores it in the live RAM state setNotes(json.data). It broadcasts this via <NoteContext.Provider value={{ notes }}>.

4. Notes.jsx (Parent Component): Uses useContext(NoteContext) to grab the notes array from the air, loops through it via .map(), and passes each single note object down to the child card.

5.NoteItem.jsx (Child Component): Reads note._id from its properties and feeds it directly into your network delNote(id) function when the trash can icon is clicked!
