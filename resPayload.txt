In APIs, payload means the actual data being sent in a request.
Think of an HTTP request like sending a parcel 📦:
URL → where you're sending it
Method → what you're doing (GET, POST, etc.)
Headers → information about the request
Payload/body → the actual data inside the parcel


More precisely, in HTTP terminology, the payload is the request body containing the data your API needs.

Your frontend sends:
fetch("http://localhost:5000/api/v1/users/login", {
  method: "POST",
  headers: {
    "Content-Type": "application/json"
  },
  body: JSON.stringify({
    email: "abc@gmail.com",
    password: "123456"
  })
});
Here, this is the payload:
{
  "email": "abc@gmail.com",
  "password": "123456"
}


After checking the credentials, your backend might send:
return res.status(200).json(
  new ApiResponse(
    200,
    { user, accessToken },
    "User logged in successfully"
  )
);
The data being returned:
{
  user: {...},
  accessToken: "eyJ..."
}
is the response payload.
